# SE_lab_s2

## تغییرات اعمال‌شده

### Dependency Injection
- تعریف `PaymentGateway` به عنوان یک رابط (interface) برای امکان پیاده‌سازی درگاه‌های متنوع
- ایجاد پیاده‌سازی `ExternalPaymentGateway` جهت مدیریت پرداخت از طریق APIهای خارجی (افزایش انعطاف‌پذیری و تست‌پذیری)
- تعریف `ConfigManager` به عنوان یک interface جهت جداسازی منطق بارگذاری پیکربندی
- پیاده‌سازی `EnvConfigManager` برای بارگذاری اطلاعات از متغیرهای محیطی (`System.getenv()`) به جای مقادیر hardcoded
- استفاده از کانستراکتور برای تزریق وابستگی‌ها به کلاس `PaymentProcessor` به منظور کاهش coupling

### ایزوله‌سازی و جداسازی ماژول‌ها
- انتقال منطق پردازش پرداخت به کلاس مجزای `ExternalPaymentGateway`
- انتقال بارگذاری پیکربندی به کلاس مستقل `EnvConfigManager`
- حذف ارجاع مستقیم به مقادیر و آدرس‌های API از کلاس اصلی و جایگزینی با وابستگی تزریق‌شده
