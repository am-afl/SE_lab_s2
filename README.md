## طراحی رابط PaymentGateway

### هدف

هدف از این پروژه طراحی و پیاده‌سازی یک سیستم ماژولار برای مدیریت پرداخت‌ها است که در آن، منطق مربوط به هر درگاه پرداخت (مانند Stripe، PayPal و ...) از منطق اصلی سیستم جدا شده و از طریق یک رابط (Interface) قابل کنترل باشد. این ساختار امکان گسترش آسان و نگهداری بهتر سیستم را فراهم می‌کند.

---

### اجزای سیستم

#### 1. **رابط PaymentGateway**
```java
public interface PaymentGateway
```
- این رابط مشخص‌کننده‌ی امضای متدهای مورد نیاز برای هر درگاه پرداخت است.
- متدهای تعریف‌شده:
    - `processPayment`: پردازش پرداخت
    - `refundPayment`: بازپرداخت
    - `getTransactionStatus`: بررسی وضعیت تراکنش

---

#### 2. **کلاس BaseGateway**
```java
public abstract class BaseGateway implements PaymentGateway
```
- این کلاس پایه‌ای است که منطق مشترک بین همه‌ی درگاه‌ها را پیاده‌سازی می‌کند.
- متدهای `refundPayment` و `getTransactionStatus` در این کلاس پیاده‌سازی شده‌اند تا تکرار کد در پیاده‌سازی‌های مختلف کاهش یابد.

---

#### 3. **درگاه‌های پرداخت (StripeGateway و PayPalGateway)**

- این کلاس‌ها از `BaseGateway` ارث‌بری می‌کنند و فقط منطق مربوط به `processPayment` را پیاده‌سازی می‌کنند.
- هر کلاس دارای endpoint مخصوص خود است و در زمان پردازش اطلاعات مشتری، یک شناسه تراکنش منحصربه‌فرد تولید می‌کند.

---

#### 4. **کلاس PaymentProcessor**
```java
public class PaymentProcessor
```
- این کلاس مسئول تعامل با درگاه پرداخت است.
- در اینجا مفهوم **چندریختی (Polymorphism)** پیاده‌سازی شده است: شیء از نوع `PaymentGateway` دریافت می‌کند اما در زمان اجرا می‌تواند به هر پیاده‌سازی از آن متصل شود (مثلاً Stripe یا PayPal).

---

#### 5. **کلاس Main**
```java
public class Main
```
- این کلاس برای اجرای نمونه‌ای از عملکرد برنامه طراحی شده است.
- ابتدا درگاه Stripe، سپس PayPal به `PaymentProcessor` تزریق می‌شود تا قدرت چندریختی به نمایش گذاشته شود.

---

###  اصول شی‌گرایی پیاده‌سازی‌شده

- اصل Encapsulation :اطلاعات محرمانه‌ی هر درگاه و عملیات مربوطه در کلاس‌های جداگانه نگهداری می‌شوند. 
- اصل Abstraction : رابط `PaymentGateway` عملیات انتزاعی سیستم پرداخت را تعریف می‌کند.
- اصل Inheritance : کلاس‌های `StripeGateway` و `PayPalGateway` از `BaseGateway` ارث‌بری می‌کنند.
- اصل Polymorphism : کلاس `PaymentProcessor` از طریق شی‌ای از نوع `PaymentGateway` با همه درگاه‌ها کار می‌کند.
